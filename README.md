# aap-misc

Various AAP-related things

## aap-downloads.py

List or download any available AAP installer files from the Red Hat portal.  Requires a Red Hat API offline-token, see [generating an access token](https://access.redhat.com/articles/3626371#bgenerating-an-access-tokenb-4) for information on creating one.

## manage-aap.sh

Stop, start, or restart the containerized AAP services.  Add to `$HOME/.local/bin` of the user running the AAP containers.
